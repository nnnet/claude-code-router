## Context

Существующий `openrouter-free-models.sh` совмещает загрузку каталога, разбор размеров моделей, OpenRouter-специфичные endpoint metrics, проверку аккаунта и пять renderers. Каталоги OrcaRouter, TeamoRouter и Kilo Gateway OpenAI-compatible лишь частично: признаки бесплатности и полнота metadata различаются, а аналога OpenRouter endpoint pages у них нет.

## Goals / Non-Goals

**Goals:**

- единая реализация форматов, сортировки и кэша для трёх новых команд;
- явная провайдер-специфичная нормализация бесплатности и account access;
- безопасная передача Bearer-токена непосредственно из окружения через curl;
- детерминированные BDD-проверки без обращения к production API.

**Non-Goals:**

- изменение существующего OpenRouter-скрипта;
- имитация метрик, которые провайдер не публикует;
- выполнение inference-запросов для проверки каждой модели;
- унификация внутренних каталогов провайдеров сверх полей публичного контракта.

## Decisions

1. **Общий движок и тонкие wrappers.** Три команды передают идентификатор провайдера общему Bash-движку. Это гарантирует одинаковые параметры и renderers. Альтернатива с тремя копиями отклонена из-за неизбежного расхождения форматов и тройного сопровождения.
2. **Нормализация до общей catalog shape.** Исходный объект модели сохраняется, а свободные признаки используются только для отбора и access map. Отсутствующие metadata остаются `null`. Альтернатива с enrichment из стороннего каталога отклонена как источник недостоверных данных.
3. **Ключ импортируется curl по имени переменной.** Используется `--variable`/`--expand-header`, поэтому значение не появляется в argv. Кэш содержит только ответы каталога, которые не включают ключ.
4. **Endpoint metrics имеют стабильную пустую схему.** `--with-endpoints` остаётся совместимым параметром, но без публичного источника значения latency/throughput/uptime не вычисляются.
5. **BDD использует `file://` fixtures.** Это проверяет CLI, фильтрацию, кэш и все форматы без нестабильности сети и расхода квоты.

## Risks / Trade-offs

- [Каталог провайдера меняет схему] → строгая проверка `.data` и fixtures для известных вариантов; ошибка не затирает последний исправный кэш.
- [Публичный каталог и доступ конкретного ключа различаются] → при наличии ключа каталог запрашивается с ним, а отсутствие account endpoint явно отражается как неизвестная квота.
- [curl старее 8.3] → команда завершится понятной ошибкой при невозможности безопасно импортировать ключ; небезопасный fallback с ключом в argv не используется.
- [Провайдер публикует новые бесплатные признаки] → правила изолированы по provider id и могут расширяться без изменения renderers.

## Migration Plan

Новые файлы добавляются без изменения существующих команд. Откат состоит в удалении трёх wrappers и общего движка; пользовательские конфигурации OpenRouter не затрагиваются.
